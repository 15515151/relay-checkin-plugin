安全IMPORTANT
令牌、Session 和站内密码不要发送到群里。AgentRouter 自动领取每日 $25，需要先重置站内密码，再使用“邮箱 + AgentRouter 站内密码”绑定；这里不是 GitHub 或 LinuxDO 密码。
叁使用说明章节三 / 3
01群里推荐只发“#中转添加 地址”，敏感凭据私聊补发，绑定结果会回到原群提示。
02机器人开启 disablePrivate 时，主人需在 disableAdopt 中加入“中转”，私聊改发“中转绑定 凭据”。
03同一站点可添加多个账号，数据按 QQ 隔离，删除和定时操作只影响自己。
04定时结果会推送到 push_groups.json 中配置的每一个群，内容包含全部定时签到用户。
05AgentRouter Cookie 账号只能查询余额；自动签到请使用“#中转添加邮箱”。
06支持 new-api、Veloera 及同源魔改站；Turnstile 站点会自动尝试浏览器方案。
07AnyRouter 有阿里云 WAF，浏览器签到耗时较长属于正常现象。
